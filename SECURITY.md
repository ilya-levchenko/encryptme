# Политика безопасности

## Поддерживаемая версия

Исправления безопасности выпускаются для последней версии в ветке `main`.

## Сообщить об уязвимости

Не публикуйте детали уязвимости в обычном issue. Используйте **Security → Report a vulnerability** в GitHub. Если private vulnerability reporting недоступен, создайте issue без технических подробностей и попросите владельца открыть приватный канал связи.

Укажите затронутую платформу, версию, ожидаемое и фактическое поведение, минимальные шаги воспроизведения и оценку влияния. Никогда не прикладывайте реальные дневники, пароли, сертификаты или provisioning profiles.
