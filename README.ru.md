# EncryptMe

Локальный зашифрованный дневник для Windows, macOS, Linux, iOS и Android. Настоящий пароль открывает основной сейф, запасной — отдельный правдоподобный сейф. Облачного аккаунта и телеметрии нет.

## Возможности

- отдельное AES-256-GCM-шифрование индекса и каждой записи;
- календарь, несколько записей в день, форматирование и анимированные маски;
- русский и английский интерфейс, автоопределение и переключение без перезапуска;
- автоблокировка, ручная блокировка и безопасный экран последних приложений;
- общий зашифрованный backup для всех платформ;
- Windows ↔ смартфон по локальному Wi-Fi и QR-коду;
- iPhone ↔ iPhone, Android ↔ Android и iPhone ↔ Android по Bluetooth LE.
- добровольные локальные напоминания вернуться к дневнику и поддержать проект.

## Запуск и сборка

```bash
git clone https://github.com/ilya-levchenko/encryptme.git
cd encryptme
npm ci
npm run dev
```

Для Android нужны JDK 21 и Android SDK 36. Команды: `npm run build:ios`, `npm run build:android`, `npm run dist:win`. GitHub Actions создаёт debug APK без секретов; подписанные APK/AAB собираются после настройки ключа по [инструкции](docs/android.md).

## Синхронизация

Для Windows и телефона запустите сеанс Wi-Fi на компьютере и отсканируйте QR-код в мобильном EncryptMe.

Для двух телефонов откройте один сейф на обоих устройствах. На первом нажмите **Разрешить подключение рядом**, на втором — **Найти телефон рядом**. Сеанс живёт пять минут, принимает одно устройство и завершается при блокировке или уходе в фон. В BLE-рекламе нет имени профиля, дат, заголовков или ID записей.

Независимо созданные сейфы не объединяются. Для первой общей копии экспортируйте зашифрованный backup на одном устройстве и импортируйте на втором. Подробности: [docs/bluetooth.md](docs/bluetooth.md).

## Локальные напоминания

Мобильное приложение запрашивает системное разрешение на уведомления при первом видимом запуске. Напоминание вернуться к дневнику через три дня остаётся добровольным. Ежемесячное предложение поддержать проект включено по умолчанию на Windows и Android без отдельного переключателя; на iOS оно включается только отдельной галочкой явного согласия и может быть отключено там в любое время. Тексты создаются на русском или английском полностью на устройстве: серверов, push-токенов, телеметрии и содержимого дневника в уведомлениях нет.

Каждое открытие EncryptMe переносит трёхдневное напоминание. На Windows при активном напоминании приложение включает скрытый запуск вместе с системой. Если уведомления были запрещены, разрешите их для EncryptMe в настройках ОС и перезапустите приложение.
