# Участие в разработке

Спасибо за интерес к EncryptMe. Для изменений, затрагивающих формат сейфа, импорт, экспорт или криптографию, сначала откройте issue и опишите совместимость и модель миграции.

## Локальная разработка

1. Установите Node.js 22+.
2. Выполните `npm ci`.
3. Запустите desktop-режим командой `npm run dev`.
4. Перед pull request выполните `npm run check`.

Для iOS используйте `npm run build:ios`, затем откройте `ios/App/App.xcodeproj` в Xcode 26+. Генерируемый каталог `ios/App/App/public` не коммитится.

## Pull request

- Делайте одну логическую задачу на pull request.
- Не меняйте формат шифрования без теста совместимости Electron ↔ Web Crypto.
- Не добавляйте телеметрию, удалённую загрузку кода или сетевое хранение дневника.
- Не коммитьте сертификаты, provisioning profiles, `.env` и реальные резервные копии.
- Обновляйте документацию при изменении поведения пользователя.
