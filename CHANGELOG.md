# Changelog

Все заметные изменения проекта документируются здесь. Формат следует Keep a Changelog, версии — Semantic Versioning.

## [1.5.0] - 2026-09-12

### Added

- полный русский и английский интерфейс с системным выбором и ручным переключением без перезапуска;
- Android-проект Capacitor с приватным хранилищем, `FLAG_SECURE`, импортом/экспортом и функциональным паритетом общего интерфейса;
- мобильная BLE-синхронизация на CoreBluetooth и Android GATT с пяти минутными одноразовыми сеансами, прогрессом и обезличенной рекламой;
- транспортно-независимое детерминированное слияние записей и tombstone-маркеров;
- раздел «О приложении» с автором, контактами, исходным кодом, MIT и пожертвованием USDT TRC20;
- GitHub Actions для debug APK и подписанных release APK/AAB.

### Security

- BLE-пакеты дополнительно аутентифицируются AES-GCM ключом открытого сейфа и проверяются SHA-256;
- Android cloud backup отключён, содержимое скрыто из снимков и Recent Apps;
- внешние ссылки ограничены точным email автора и разрешёнными HTTPS-хостами.

## [1.4.0] - 2026-09-12

### Added

- Windows показывает локально сгенерированный QR-код активного пятиминутного сеанса синхронизации;
- iOS сканирует QR-код нативной камерой и автоматически запускает обмен зашифрованным сейфом;
- QR-пакет строго проверяет версию протокола, приватный IPv4-адрес и 12-значный одноразовый код;
- ручной ввод адреса и кода сохранён как резервный способ подключения.

### Fixed

- сетевой ответ синхронизации больше не содержит лишнюю расшифрованную копию данных; передаются только зашифрованный контейнер и статистика.

## [1.3.1] - 2026-09-09

### Fixed

- одноразовый код Wi-Fi-синхронизации теперь состоит только из цифр и открывает цифровую клавиатуру iOS;
- кнопка синхронизации больше не остаётся молча недоступной из-за раскладки клавиатуры: неполный ввод объясняется сообщением;
- вставленный код автоматически очищается и форматируется группами по четыре цифры.

## [1.3.0] - 2026-09-09

### Added

- прямая синхронизация открытого сейфа между Windows и iPhone в одной Wi‑Fi-сети;
- временный Windows-узел со случайным портом, одноразовым кодом, пятиминутным сроком и ограничением попыток;
- поэлементное объединение записей и зашифрованные tombstone-маркеры удалений;
- отдельные мобильный и desktop-интерфейсы подключения в настройках;
- проверка совместимости ключа, исключающая смешивание настоящего, запасного или постороннего сейфа.

## [1.2.4] - 2026-09-09

### Fixed

- резервные копии с расширением `.encryptme-backup` больше не отображаются серыми в системном выборе файлов iOS;
- нативный импорт ожидает фактический выбор или отмену файла и не завершается преждевременно при возврате из iOS Files;
- тип зашифрованной резервной копии EncryptMe зарегистрирован в iOS.

## [1.2.3] - 2026-09-09

### Added

- в настройках и на экране заблокированного сейфа появился безопасный выход для смены аккаунта с последующим входом или импортом зашифрованной копии.

### Fixed

- повторное нажатие на цитату снимает цитирование вместо создания вложенной цитаты;
- кнопки форматирования показывают активное состояние и повторным нажатием снимают соответствующий стиль;
- повторное применение маски к уже скрытому выделению снимает маску.

## [1.2.2] - 2026-09-09

### Changed

- основной и запасной сейфы используют общий KDF-salt, поэтому при входе достаточно одного вычисления ключа;
- новые и автоматически обновлённые сейфы используют системный PBKDF2-HMAC-SHA-256 вместо медленного JavaScript-scrypt на iOS;
- существующие профили автоматически запоминают salt открытого сейфа, а второй сейф переводится на него после первого открытия.

### Fixed

- окончательно отцентрирована иконка добавления записи;
- количество записей больше не переносится под подпись «Записи дня».

## [1.2.1] - 2026-09-09

### Added

- нативная микровибрация для кнопок и отдельный selection-feedback при смене даты или записи;
- пружинная анимация карусели дат и списка записей;
- прогрессивные стеклянные материалы для поддерживаемых версий iOS.

### Fixed

- двойной верхний отступ WebView на iOS;
- центрирование кнопки добавления и вертикальное выравнивание нижней панели;
- сокращённый статус «Сохранено» с анимированной иконкой дискеты.

## [1.2.0] - 2026-09-09

### Added

- отдельное шифрование каждой записи и расшифровка текста только при выборе;
- автоматическая атомарная миграция старого монолитного сейфа;
- мобильная карусель дат и постоянно видимый список записей выбранного дня;
- кнопка настроек в верхней мобильной панели и красная иконка удаления.

### Fixed

- подсчёт слов в форматированном тексте и нумерованных списках;
- undo/redo для форматирования и скрытых фрагментов;
- масштабирование интерфейса при вводе на iOS.

## [1.1.0] - 2026-09-08

### Added

- нативный проект iOS на Capacitor 8;
- совместимая реализация AES-256-GCM/scrypt на Web Crypto;
- iOS-хранилище, импорт, экспорт и блокировка при уходе в фон;
- защита снимка приложения и `NSFileProtectionComplete` для каталога сейфа;
- GitHub Actions для CI, unsigned/signed IPA и опционального TestFlight upload;
- публичная документация и файлы участия в проекте.

### Changed

- репозиторий приведён к структуре публичного open-source проекта;
- mobile layout учитывает safe area и динамическую высоту viewport;
- desktop-пакет исключает исходные `node_modules` из устанавливаемого приложения.
